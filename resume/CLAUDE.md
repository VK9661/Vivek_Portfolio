## Folder layout
- `Graphic_Designer/`, `UI_UX_Designer/`, `Motion_Graphic_Designer/`, `All_Roles/` – each holds a base JSON and its PDF.
- `build_resume.py` + `fonts/` – the builder. `python build_resume.py <folder>/<file>.json` writes the PDF next to the JSON.
- A JD-tailored resume goes in the matching role folder (balanced / mixed roles go in `All_Roles/`), named `Vivek_Kumar_[Company]_Resume.pdf` (use the role if the company is unknown), with its JSON next to it. Copy the closest base JSON, edit it, build.

## Workflow
1. Extract from the JD: role title, must-haves, nice-to-haves, tools, culture words.
2. Map each must-have against my data as MATCH, PARTIAL or GAP. Show this in a few lines.
3. Pick the closest base (Graphic, UI/UX, Motion, All Roles) and tailor: title, profile (3 sentences), skills order, tools order, bullet wording, which projects to show.
4. Build and verify. Report: keyword match (X/Y), what changed, gaps list for interview prep.
